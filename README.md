# Muscle Meals

A static web app (HTML, CSS, JS). No build step, no dependencies. Data saves in the visitor's browser.

## Host it free on GitHub Pages
1. Create a new GitHub repository and upload everything in this folder (keep `index.html` at the top level).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After about a minute your app is live at `https://<your-username>.github.io/<repo-name>/`.

## Files
- `index.html` – landing page and app markup
- `css/site.css` – scroll animations and landing styles
- `css/app.css`, `js/app.js` – your original planner
- `js/site.js` – scroll effects, today card, streaks
